WEB PROJESİ: Türkçe yazı düzeltim ve metin yazdırma sitesi.

Hangi sorunu çözer: Türlçe gibi zor dilde yazım kuralları, noktalama işareti ve büyük harf küçük harf yazımı oldukça zordur, şahsen bende bu kuralları pek beceremiyorum. bu proje ise bir metin yazdığımda o metni TDK kurallarına göre düzenleyecek ve benim ve benim gibi Türkçe'de zorlananların problemini çözecek.

Projenin hedefleri: 1) Sistem arayüzü ve görsel tasarımını yapmak.
2) Noktalama işareti düzenleyici eklemek.
3) Yazım Kuralları düzenleyici eklemek.
4) Büyük harf küçük harf yazımı düzenleyicisi eklemek.
5) Açıklayıcı Anlatım metni üreticisi eklemek.
6) Öyküleyici Anlatım metni üreticisi eklemek.
7) Betimleyici Anlatım metni üretici eklemek.
8) Tartışmacı Anlatım metni üreticisi eklemek.

Projenin özellikleri: 1) Yazılan bir metni noktalama işaretleri, yazım kuralları ve büyük harf küçük harf kurallarına göre düzeltir.
2) Random yada verilen bilgilere göre Türkçedeki Temel Anlatım Biçimleri tarzında metin oluşturacak. Metnin hangisi olacağı ve nasıl olacağı kullanıcının verdiği bilgilere kalmıştır.
Projede kullanılacak yazımlım dilleri ve diğer etkenler: 1) HTML
2) CSS
3) C# 
4) Java
5) kendim tarafındam eğitilmiş projeye yönelik yapay zeka(eğer gerek kalırsa)
